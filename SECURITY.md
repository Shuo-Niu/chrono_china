# Security policy

## Supported versions

ChronoChina is currently a research MVP. Security fixes are applied to the
latest revision of `main`; no older release line is supported yet.

## Reporting a vulnerability

Do not open a public issue for a vulnerability, leaked credential, or data
exposure. Use GitHub's private vulnerability reporting / Security Advisory
workflow for this repository. Include reproduction steps, affected files or
versions, and the potential impact.

Do not include third-party dataset archives, access tokens, personal data, or
temporary signed download URLs in a report or pull request.

## Scope note

The repository is a local research application, not a production service.
Third-party data licensing concerns should be reported as data-governance
issues unless they also create a software security problem.
