# ChronoChina v0.1.1 — Maintenance Pre-release

2026-10-19 · Source-only / 仅源码发布

## 中文

本版固定已验证的维护成果，仍属于研究原型的预发布版本。

- 支持连续精确年份、视口驱动探索、手动历史单位类别开关、点/标签显示和同坐标记录交互。
- 以独立覆盖元数据区分快照、连续记录、有限覆盖与当前范围无记录；保留真实历史记录的原始有效时间。
- 提供固定的“极简 / 标准 / 丰富”离线参考地图构建流程；补齐样式引用的全部四种字体，并验证字形资源。
- 清末制度小识的审核记录与正式发布状态保持一致；内容按精确来源类型与 1901—1911 年范围匹配。
- 支持实际单文件 Windows portable 自动验证，包括运行时版本、离线资源、历史点详情与关闭重开。
- 同步 Python、Web 与桌面版本号为 0.1.1，并纳入此前合并的依赖与安全维护。

开发环境支持 Python 3.11+，以及 Node.js `^22.12.0`、`^24.0.0` 或 `>=26.0.0`，推荐 Node 24。桌面运行时为 Electron 44.5.1。

GitHub Release 仅发布代码、项目原创说明、审核记录与数据获取管道。第三方历史记录、原始或标准化索引、离线地图档案和本地 portable EXE 不在本次发布中。打包工具和自动验证可用，不代表数据再分发授权已经确认。

本版没有迁移 V6、补造历史记录、扩充制度小识内容，或宣称已完成独立 Windows 设备与 3–5 人可用性测试。通过构建和自动验证也不代表正式 Beta 验收。

## English

This maintenance pre-release fixes a reviewed research-prototype baseline.

- Exact-year viewport exploration, manual historical-unit categories, point/label controls, and co-located-record interaction.
- Separate coverage metadata for snapshots, interval records, limited support, and empty viewport results, preserving source validity dates.
- Reproducible minimal, standard, and rich offline reference-map styles; all four required font stacks are bundled and glyph loading is checked.
- Reviewed Qing institution-note publication records, matched by exact source type within 1901–1911.
- Automated verification of the actual standalone Windows portable, including runtime version, offline resources, historical details, and close/reopen.
- Python, Web, and desktop versions aligned to 0.1.1, incorporating previously merged dependency and security maintenance.

Development requires Python 3.11+ and Node.js `^22.12.0`, `^24.0.0`, or `>=26.0.0`; Node 24 is recommended. The desktop runtime is Electron 44.5.1.

This GitHub release contains source code, project-authored explanations and review records, and acquisition pipelines. It does not distribute third-party historical records, raw or normalized indexes, offline map archives, or the locally built portable EXE. Packaging and automated validation do not establish data redistribution permission.

This release does not migrate to V6, fabricate records, expand institution-note content, or claim completion of independent Windows testing or a 3–5 person usability study. It remains a pre-release, not a validated Beta.
