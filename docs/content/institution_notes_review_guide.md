# ChronoChina 制度小识审核指南

## 审核对象

审核单位是可复用的制度知识条目，不是历史点。一个审核通过的“清末的县”条目可以服务所有满足类型、年份和适用范围条件的县记录，因此不需要逐条审核数千个地点。

本轮机器可读草案：

`data/knowledge/drafts/qing_late_institution_notes_v0.1.json`

逐条阅读稿：

`docs/content/qing_late_institution_notes_review.md`

## 三种审核结论

- `APPROVE`：事实、措辞、适用范围均可接受，可以进入来源复核与发布准备。
- `REQUEST_CHANGES`：方向可用，但需要具体修改。请写明希望替换的句子或问题。
- `HOLD`：证据不足、概念争议过大，或当前没有必要公开。

不要直接把 `DRAFT` 改为 `PUBLISHED`。批准只代表内容审核通过，仍需完成引用复核、匹配测试和 UI 人工审核。

## 每条只检查五件事

1. **事实**：正文是否与所列来源相符？
2. **范围**：它是否把清代内地的一般情况误写成全国无例外的制度？
3. **层级**：是否错误地把“道”“州”或“厅”说成永远固定的一层？
4. **可读性**：普通用户是否能一次读懂，是否还有不必要术语？
5. **价值**：读完是否比只看到“府”“州”“县”更了解制度背景？

## 建议审核顺序

先审核最关键的概念风险，再审核较稳定的类型：

1. 清末地方制度并非整齐的单一层级
2. 清末的道
3. 清末的州
4. 清末的厅
5. 清末的府
6. 清末的直隶州
7. 清末的省
8. 清末的县

## 回复格式

在聊天中按下面格式回复即可：

```text
条目：qing_late_system_overview
结论：APPROVE / REQUEST_CHANGES / HOLD
意见：无，或写具体修改意见
```

也可以一次审核多条：

```text
qing_late_system_overview: APPROVE
qing_late_dao: REQUEST_CHANGES — “派出或办事机构”需要更口语化
qing_late_zhou: HOLD — 我还不确定是否要向普通用户解释两种州
```

## 发布规则

- 只有 `APPROVE` 条目可以进入下一步。
- 发布版必须保留来源 ID、适用 raw type 和适用年份。
- raw type 或制度位置不明确时不显示，而不是选择最相近的条目。
- 多个候选条目冲突时不显示。
- 条目正文必须是原创转述，不复制现代研究著作的段落。
- 本轮所有条目的 `auto_match_enabled` 和 `publication_eligible` 均为 `false`。

## 当前已知限制

- 本批仅处理 1901—1911 年的清末制度背景。
- 当前没有建立全国统一的 region → regime 映射。
- raw type `州` 和 `厅` 不能单独证明具体层级。
- “厅”条目在正式发布前仍需复核北京大学学报论文全文。
- 本批不解释具体地点的设立、迁治、改名或继承关系。
