ChronoChina Phase 1.5 — Windows 真人可用性测试版
===================================================

系统要求：Windows 10/11 x64。不需要安装 Node.js、Python 或其他开发工具。

如何启动
--------
双击 ChronoChina-Phase1.5-Portable-0.1.0-x64.exe。它不需要安装，首次启动可能稍慢。

离线地图
--------
历史点、时间轴、资料覆盖提示和中国区域现代参考地图均已包含在应用中。
正常浏览不需要网络，也不需要开发服务器；地图不会在每次启动时重新下载。
内置地图最高缩放级别为 z9，超出此级别时不会出现更多现代地图细节。

Windows SmartScreen
-------------------
这是未签名的封闭测试版，Windows 可能显示 SmartScreen 警告。
如果文件来源和 SHA-256 已由测试组织者确认，可选择“更多信息”→“仍要运行”。
如果你不确定文件来源，或校验值不一致，请选择“不运行”并联系测试组织者。

如何关闭
--------
点击窗口右上角的 ×。再次双击应用即可重新打开。

启动失败
--------
记录看到的错误文字和发生时间，并发送以下日志给测试组织者：
%APPDATA%\ChronoChina\logs\main.log

请不要公开上传或转发本测试包。本版本包含许可状态尚待书面确认的历史数据衍生资产。
